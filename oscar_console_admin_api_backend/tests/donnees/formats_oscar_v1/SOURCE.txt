Copie des formats OSCAR, prise à une étiquette fixe du dépôt qui en est la source.

La console ne lit pas ces fichiers en service : ses tests les lisent, pour
vérifier que le format du bundle (app/studio_modele/formats.py) et les règles du
modèle (app/studio_modele/regles.py) disent la même chose que la source, cas par
cas. Le navigateur garde sa propre copie des mêmes cas.

Ne modifiez jamais ces fichiers à la main : tests/test_studio_formats.py compare
chacun à son empreinte ci-dessous. Pour passer à une autre étiquette, clonez le
dépôt à cette étiquette, recopiez les fichiers listés (même chemin, sous le
dossier de la source), puis remplacez l'étiquette, le commit et les empreintes
de ce fichier par ceux que donne, dans le dossier de la source :
  sha256sum <les fichiers listés>
